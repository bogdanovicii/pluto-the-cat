# 04a — How the vanilla pasts are built (Convict, Hunter, Pilot, Marine, Robot, Bullet, Cultist)

Research date 2026-09-14. Sources: decompiled game code (fedes1to/EtG-source `ExportedProject/Assets/MonoScript/Assembly-CSharp/*.cs`, full coroutine bodies; FlowSand/Re-ETG `Assets/_RawDump/C#/Assembly-CSharp/*.cs`, same assembly, bodies stripped), exported asset YAML (fedes1to `ExportedProject/Assets/{Asset_Bundles/dungeons,MonoBehaviour,Prefab}`), enterthegungeon.wiki.gg pages, mtgmodders gitbook "Enemy Guids", ModTheGungeon/ETGMod `enemies.txt`. Items marked **[uncertain]** are inferred. Complements `03-alexandria-custom-past.md` §4 and `04-past-level-and-dungeonapi.md` §1.6 (ending sequence, flags, DungeonAPI).

## 0. TL;DR — the reusable skeleton

- A vanilla past = `GameLevelDefinition` (`fs_*`) → `Dungeon` prefab `FinalScenario_*` (asset bundle `dungeons/finalscenario_*`) → one `DungeonFlow` (`Ending_Scenario_*_Flow`) → **one hand-built `PrototypeDungeonRoom`** (`*_End_Room`, category `ENTRANCE = 7`, no exits) whose *only* base-layer placed object is a giant scene prefab (`EndingRoom_*`: tiles/props/NPC `TalkDoerLite`s/the `*PastController`), plus the boss in `additionalObjectLayers[0]` and the boss' adds in a reinforcement layer. Exception: the Bullet's past is 4 small `NORMAL` rooms chained by warp points.
- All six share **one tileset**: `tilesetId: 16384` (`ValidTilesets.FINALGEON`), one `dungeonCollection` (guid `0729565a2b6877d438f3b47b84e61997`), one `DungeonMaterial` (`079077847dfb74444be2e4b005dc61e8`), one `fallbackRoomTable` (`26d4250da47b1c340a587279656d63f7`), `LevelOverrideType: 5` (`CHARACTER_PAST`), `DISABLE_LOOPS: 1`, `BossMasteryTokenItemId: -1`, `PlayerIsLight: 0`. The look comes from the placed scene prefab, not from tiles.
- Scripting = one `MonoBehaviour` per past (`ConvictPastController`, `GuidePastController`, `PilotPastController`, `PastLabMarineController`, `RobotPastController`, `BulletPastRoomController` ×4, `CoopPastController`) with a `Start()` coroutine: `while (Dungeon.IsGenerating) yield return null;` → `Pixelator.Instance.TriggerPastFadeIn()` → `PastCameraUtility.LockConversation(pos)` → `talkDoer.Interact(player); while (talkDoer.IsTalking) yield return null;` → scripted movement (`TalkDoerLite.PathfindToPosition` + `GetPathVelocityContribution`) → `PastCameraUtility.UnlockConversation()` → find the boss (`StaticReferenceManager.AllHealthHavers` where `IsBoss` and `GenericIntroDoer.triggerType == BossTriggerZone`), `ObjectVisibilityManager.ChangeToVisibility(CURRENT)`, `GenericIntroDoer.TriggerSequence(player)`.
- Boss death: a `BossFinal*DeathController` on the boss subscribes `healthHaver.OnPreDeath` and calls `FindObjectOfType<XPastController>().OnBossKilled()`; that sets `GameStatsManager.SetCharacterSpecificFlag(<char>, KILLED_PAST, true)` (+ `BOSSKILLED_*_PAST`, `RegisterStatChange(TIMES_KILLED_PAST, 1)`), plays an epilogue conversation, `Pixelator.FreezeFrame()` + `BraveTime.RegisterTimeScaleMultiplier(0f)` for `ConvictPastController.FREEZE_FRAME_DURATION = 2f`, `new TimeTubeCreditsController().HandleTimeTubeCredits(player.sprite.WorldCenter, false, null, -1)` (after `ClearDebris()`, usually `Pixelator.FadeToColor(0.15f, Color.white, true, 0.15f)`), `AmmonomiconController.Instance.OpenAmmonomicon(true, true)`.

## 2. Dialogue, camera and scripted-event toolkit (shared by all pasts)

- **NPC conversations** are `TalkDoerLite` components (fields: `speakPoint`, `audioCharacterSpeechTag`, `playmakerFsms`, `MovementSpeed`, `PathfindToPosition(pos, path, cellValidator)`, `GetPathVelocityContribution(lastPos, 16)`, `ShowText(...)`, `ForceTimedSpeech(...)`, `HostileObject`). `Interact(player)` only does `SendPlaymakerEvent("playerInteract")`; the NPC's PlayMaker FSM then runs `DialogueBox` actions (`dialogue[]` = string-table keys, `responses[]`+`events[]` = player choices such as "Teach them a lesson", `PlayBoxOnInteractingPlayer` ("Only for Pasts!" — box over the player), `IsThoughtBubble`, `AlternativeTalker`, `zombieTime`, `forceCloseTime`, `OverrideTalkAnim`), ends with `EndConversation` (clears input override "conversation", letterbox, HUD). Controllers poll `while (td.IsTalking) yield return null;` and read FSM variables (`td.playmakerFsm.FsmVariables.FindFsmBool("giftGiven")`, `td.GetDungeonFSM().FsmVariables.GetFsmBool("recenter")`) or fire events (`playmakerFsm.SendEvent("playerInteract")`).
- **NPC → enemy**: FSM action `BecomeHostile { FsmString enemyGuid; TalkDoerLite alternativeTarget; }` hides the TalkDoer (`SetNpcVisibility`), `AIActor.Spawn(EnemyDatabase.GetOrLoadByGuid(guid), talkDoer.specRigidbody.UnitCenter, room)`, `HasBeenEngaged = true`, triggers the actor's `GenericIntroDoer` if any. Other `.NPCs` actions worth knowing: `BeginConversation`, `WalkToPlayer`, `Teleport`, `SetCharacterSpecificSaveFlag`, `SpawnEnemies`, `GiveConsumable`, `PhantomDoor`, `CutToCamera`, `BroadcastEventInRoom`, `Tk2dPlayAnimation`, `PlaySound`.
- **Ambient / narrator text without an FSM**: `TextBoxManager.ShowTextBox(pos, parentTransform, duration(-1 = manual), StringTableManager.GetString(key), audioTag, instant, slideOrientation, showContinueText)` and `ShowThoughtBubble(...)`; cleared with `TextBoxManager.ClearTextBox(parent)` after N seconds or when `BraveInput.GetInstanceForPlayer(0).WasAdvanceDialoguePressed()`. Every controller has a `DoAmbientTalk(transform, offset (0.75,1.5), key, duration, isThoughtBubble)` helper. Props you can "examine" are `PlayerCommentInteractable { CommentModule[] comments; keyIsSequential; onlyTriggerOnce; OnInteractionBegan/OnInteractionFinished }` (thought bubble over the player; e.g. the Marine's bed/papers, the Hunter's machine); `PlaymakerEventInteractable` broadcasts a room FSM event instead.
- **Cutscene camera**: `PastCameraUtility.LockConversation(Vector2)` = `SetInputOverride("past")` on all players + `Pixelator.LerpToLetterbox(0.35f)` + hide HUD + `MainCameraController.SetManualControl(true); OverridePosition = pos`; `UnlockConversation()` reverses it. Also `MainCameraController.UpdateOverridePosition(pos, speed)`, `OverrideZoomScale`, `DoScreenShake` / `DoContinuousScreenShake(settings, this)`, `Pixelator.FadeToBlack/FadeToColor/FreezeFrame/SetSaturationColorPower`, `PlayerController.ForceIdleFacePoint`, `ForceMoveInDirectionUntilThreshold`, `WarpToPoint`, `ForceBlank`, `IsVisible`, `CurrentInputState = PlayerInputState.NoInput`.
- **Boss placement**: the boss sits in the room asset's `additionalObjectLayers[0]` (`reinforcementTriggerCondition: 2` = ON_ENEMIES_CLEARED, `layerIsReinforcementLayer: 0`) with a `GenericIntroDoer` (`triggerType = BossTriggerZone`) and is often `SetActive(false)`/renderer-off until the controller triggers it; a `SpecificIntroDoer` subclass customises the intro (`PlayerWalkedIn`, `StartIntro`, `EndIntro`, `OverrideIntroPosition`, `IsIntroFinished`). Adds live in a second layer with `layerIsReinforcementLayer: 1, reinforcementTriggerCondition: 80` (ENEMY_BEHAVIOR — spawned by the boss' `SpawnReinforcementsBehavior`), optionally with a `CustomReinforceDoer` (e.g. `BossFinalConvictHegemonyReinforceDoer`: rope VFX + "rappel" animation over 2 s before the actor becomes vulnerable). Death: `healthHaver.ManualDeathHandling = true`, `OverrideKillCamTime`, `OnPreDeath += ...` in a `BossFinal*DeathController`.
- **Gates**: `DungeonDoorController.DoSeal(room)` / `SetSealedSilently(bool)` / `Open()`, `DungeonDoorSubsidiaryBlocker.Seal()`, `SpeculativeRigidbody` blockers toggled on/off (`MainDoorBlocker.enabled = true`, `ExitDoorRigidbody.enabled = false`), `RoomHandler.SealRoom()` / `OnEnemiesCleared` / `Entered` events, `WarpPointHandler.DISABLED_TEMPORARILY`, `room.TriggerReinforcementLayersOnEvent(RoomEventTriggerCondition.NPC_TRIGGER_A)`.
- `InstantBossFight` debug flag on Convict/Pilot/Robot skips the intro and triggers the boss immediately — a useful pattern for testing.

## 3. Per-past walkthroughs

### 3.1 Convict — Nightclub "Confession" (`ConvictPastController`)
Rooms: one 64×71 room = upstairs office (start, desk, Baldo/Black Stache + flunky + 4 Hegemony soldiers as `TalkDoerLite`s) → stairs → dance floor (boss, `NightclubCrowdController` dancers + `NightclubLightController` moving coloured lights) → exit to the hovercar.
Sequence (`Start`): hook `crowdController.OnPanic`; input override "past"; enable the 4 `HmonSoldiers` and re-target the four `BecomeHostile` actions in soldier[0]'s FSM to each soldier (`alternativeTarget`); `FadeToBlack` + `TriggerPastFadeIn`; `LockConversation` at the flunky's `speakPoint` +3; 6 s; thought bubble `#CONVICTPAST_THOUGHTS_01` (advance on input); `InitialTalkDoer.Interact` (flunky); camera pans −2.5; flunky pathfinds away, Baldo walks in (+25 y), soldiers path into a 4-point formation; `BaldoTalkDoer.Interact` (he ends the deal); Baldo walks out and is destroyed; `HmonSoldiers[0].Interact` (charges read, choices "Teach them a lesson" / "…again" → FSM `BecomeHostile` ×4 spawns four `convicts_past_soldier` in place of the NPCs); `UnlockConversation`; desk flip (`DeskAnimator.Play()`, child `MinorBreakable`s break, `DeskAnimatorPoof`, music state 02); wait until a player walks down to the club (x/y thresholds relative to `BaldoBossTalkDoer`); `MainDoorBlocker` closes the office; `HandleBossStart`: `LockConversation` on the boss TalkDoer, `BaldoBossTalkDoer.Interact` (speech), hide TalkDoer, move the real boss (`IsBoss`) to that spot, `TriggerSequence`. Firing any projectile/beam in the club (`PostProcessProjectile` hook) makes the crowd run to the exit and starts the boss after 3 s (`HandlePrematurePanic`).
Enemies: `black_stache` `8b913eea3d174184be1af362d441910d` (1200 HP, molotov/grenades/spin-fire/run-and-gun) + reinforcement layer of 6× `convicts_past_soldier` (Hegemony Soldier, 15 HP, 3-round bursts, `Hmon_Autorifle`) `556e9f2a10f9411cb9dbfd61e0e0f1e1`; the 4 office soldiers are the same GUID spawned via `BecomeHostile`.
Ending (`HandleBossKilled`): flags; `PhantomEndTalkDoer` shown; HUD hidden; `ExitDoorRigidbody.enabled = false`; the boss TalkDoer re-appears playing "die"; UI prefab `Global Prefabs/GoToCarPanel` ("GO TO CAR") slides in; within 5 units the `Car` plays `getaway_car_open`, within 0.8 `getaway_car_close`, players `NoInput`, exhaust particles + headlights fade in, car and player lerp 30 units right over 2 s with the camera following, freeze frame, credits, Ammonomicon. Loadout (wiki): Budget Revolver, Thompson SMG, Enraging Photo, Molotov.

### 3.2 Hunter — Blacksword Manor (`GuidePastController`)
Rooms: one tall 46×85 room, three zones by y offset from the controller: entrance hall (y>+8 → dog `#DOG_YIPYIP` + `#GUIDEPAST_ZIPIT`), antechamber (y>+29 → `#GUIDEPAST_OMINOUS` + `#DOG_YIP`), machine room (the artifact machine = `PlayerCommentInteractable TargetInteractable`, `ArtifactSprite` with smoke particles, `SpinnyGreenMachinePart` sparks). No enemies before the boss.
Sequence: `m_dog = player.companions[0]` (the Wolf "Junior", `hunters_past_dog`/`wolf` `ededff1deaf3430eaf8321d0c6b2bd80`, given by the past loadout item Wolf); boss `SetActive(false)`, the `Dr. Wolf` enemy (found by `ActorName == "Dr. Wolf"`) hidden (`IsGone`, rigidbody off). Interacting with the machine → `OnInteractionBegan` = `LockConversation` (+15.5 y) and activate `DrWolfTalkDoer`; `OnInteractionFinished` → `BossCutscene_CR`: Dr. Wolf paths 12 units toward the player, `Interact` (greeting); `HandleBulletTrap` (ring of `Global Prefabs/FakeBullet` ×3 radii around the player over 1 s) + `HandleDogGoingNuts` (dog circles the trap, barking); Dr. Wolf retreats (cell validator >8 from player), camera +5; second `Interact` (options use a Blank / give up — "give up" loops back per wiki); `player.ForceBlank()` clears the trap; third `Interact`; `UnlockConversation`, TalkDoer hidden, `TriggerBoss()` (enables the Dr. Wolf rigidbody, activates the boss). `BossFinalGuideIntroDoer`: makes the Dr. Wolf actor visible/Normal, seals the `DungeonDoorSubsidiaryBlocker`, monster drops from 14 units up (`Play_BOSS_cyborg_drop_01`), shake, 3 s.
Enemies: `dr_wolfs_monster` `8d441ad4e9924d91b6070d5b3438d066` (1250 HP; spray, bullet sword, lightning, Parteiadler pattern) + `dr_wolf` `ce2d2a0dced0444fb751b262ec6af08a` (NPC-style invulnerable, dies in 4 hits, `BossFinalGuideBuffBehavior` buffs the monster; killed automatically on boss death by `BossFinalGuideDeathController` with 10000 unstoppable damage to `BossFinalGuide_DrWolf(Clone)`). Both are placed in the room's layer 0 next to the boss.
Ending: flags; `PhantomEndTalkDoer` shown; warp guide (+dog `CompanionWarp`) to the machine; `LockConversation`; `FadeToColor(white, 1 s)`; `PhantomEndTalkDoer.Interact`; `ForceMoveInDirectionUntilThreshold(down, 5)`; freeze; credits. Loadout: Colt 1851, Sticky Crossbow, Wolf (shows as "Dog" in the Ammonomicon).

### 3.3 Pilot — Hegemony Space (`PilotPastController`, `BossFinalRogueController`)
Rooms: one 90×90 "room" of space; the only past with no walking section. The Dungeon prefab has `ForceRegenerationOfCharacters: 1` and `defaultPlayerPrefab` = the ship, so `Dungeon.GeneratePlayerIfNecessary` clears the players and instantiates `defaultPlayerPrefab`; co-op partner becomes `PlayerCoopShip`. `PlayerSpaceshipController : PlayerController` (`IsFlying`, no hands, sprite rotates with aim, lasers from `LaserShootPoints` via `bulletBank` "default", missile volley 5×N "missile" with `MissileCooldown = 1f` — the "rocket active item"; `Die` unlocks `Achievement.DIE_IN_PAST`; `ResurrectFromBossKill` full-heals).
Sequence: UI camera off, Hegemony ships hidden, `TriggerPastFadeIn`, input override; `LockConversation` between Z (`FriendTalker`) and the pilot; 5.6 s; `FriendTalker.Interact` (salvage chatter); zoom 0.5, camera +8.5, continuous shake; `AdditionalHegemonyShips` + `HegemonyShip` `ArriveFromWarp` (stretch from y+60, `Play_BOSS_queenship_emerge_01`); `HegemonyShip.Interact` (the Absolution's demand; `TheRock` gets clamped to Z's ship at animation frames 4/8); camera back, zoom 1; `FriendTalker.Interact` (Z: use the jump drive; choices "Divert all power to forward weapons" / "Escape to the Warp" → loops); `UnlockConversation`; ship TalkDoer hidden; boss `TriggerSequence`; `ToggleFriendAndJunk(false)` fades Z and the floating debris out. `BossFinalRogueController` locks the camera (`InitCamera`, zoom 0.6666, player `MovementRestrictor` to the camera bounds) and scrolls the background `Quad` (`_PositionX/_PositionY`).
Enemies: `hm_absolution` `b98b10fca77d469e80fb45f3c5badec5` (5200 HP; 22 launched "Hegemony Ships" = `BossFinalRogue_Hmon_Ship` prefab from `BossFinalRogueLaunchShips*` behaviours, not in the enemy GUID list; lasers `BossFinalRogue_Beam`, homing rockets).
Ending: `BossFinalRogueDeathController` (drift + explosions); `OnBossKilled` resurrects ship players, flags, `ToggleFriendAndJunk(true)`, warps next to Z, `FriendTalker.Interact`, freeze, credits. No guns/items carry into this past.

### 3.4 Marine — Primerdyne R&D (`PastLabMarineController`, `LabAmbientLightController`)
