# Shrine Stall Implementation Plan (2.20.0)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Breach shop where Daifuku the cat and Kinsuke the koi sell permanent per-save unlocks, in Hegemony credits, for the ten cat items, which no longer drop until bought.

**Architecture:** Alexandria's foyer meta-shop already stocks only items whose `encounterTrackable` prerequisites are unmet, prices them from their loot-table weight, and sets the unlock flag on purchase. So the mod supplies: one extended `GungeonFlags` value per item plus a string mirror for id drift, a FLAG `DungeonPrerequisite` on each of the ten items, a per-run loot-table guard as a backstop, the shop registration with a price-weighted loot table, the art, and the dialogue.

**Tech Stack:** C# net35, BepInEx, Alexandria 0.5.10 (`ShopAPI.SetUpFoyerShop`, `LootUtility`), ModTheGungeonAPI 1.9.2 (`ETGModCompatibility.ExtendEnum`, `ETGMod.Databases.Strings`), Mono msbuild, Python 3 art pipeline (`tools/*.py`), unittest + Mono case suites.

**Spec:** `docs/superpowers/specs/2026-09-17-shrine-stall-design.md`. Read it before Task 1.

## Verified API facts

Read from Alexandria 0.5.10 and MtG 1.9.2 IL. The game's `Assembly-CSharp.dll` reference is a stripped stub, so **no vanilla method body was readable**; anything about vanilla runtime behaviour is inference and belongs in the checklist.

- `Alexandria.NPCAPI.ShopAPI.SetUpFoyerShop(string name, string prefix, Vector2 position, List<string> idleSpritePaths, int idleFps, List<string> talkSpritePaths, int talkFps, string bluePrintSpritePath, GenericLootTable lootTable, CustomShopItemController.ShopCurrencyType currency, string runBasedMultilineGenericStringKey, string runBasedMultilineStopperStringKey, string purchaseItemStringKey, string purchaseItemFailedStringKey, string introStringKey, Vector3 talkPointOffset, Vector3 npcPosition, ShopAPI.VoiceBoxes voiceBox = OLD_MAN, Vector3[] itemPositions = null, float costModifier = 1f, Func<...> CustomCanBuy = null, Func<...> CustomRemoveCurrency = null, Func<...> CustomPrice = null, Func<...> OnPurchase = null, Func<...> OnSteal = null, string currencyIconPath = "", string currencyName = "", bool hasCarpet = false, string carpetSpritePath = "", Vector2? CarpetOffset = null, DungeonPrerequisite[] prerequisites = null, IntVector2? hitboxSize = null, IntVector2? hitboxOffset = null)`
- `position` is an **absolute Breach world position**, the same space as `PlutoConfig.FoyerPosition`.
- Sprite paths are **embedded-resource paths** in the calling assembly. Exactly two clips are required: `idle` and `talk`. The csproj already embeds `Resources\**\*.png`.
- The default hitbox is 20x18 px and the default hitbox **offset is discarded by a bug in Alexandria**, so pass `hitboxOffset` explicitly.
- `prerequisites` is **not** consulted when placing a Breach shop. The NPC always appears; only the stock is gated.
- `CustomShopItemController.ShopCurrencyType.META_CURRENCY` is Hegemony credits.
- With `FoyerMetaShopForcedTiers` (set by `SetUpFoyerShop`), `CustomShopController.DoSetup` stocks an item only when `po.encounterTrackable.PrerequisitesMet()` is false, prices it `Mathf.RoundToInt(wgo.weight)`, and on purchase copies the FLAG prerequisite's `saveFlagToCheck` into `SaveFlagToSetOnAcquisition`.
- `ShopAPI.defaultItemPositions` has exactly three entries.
- `DungeonPrerequisite.CheckConditionsFulfilled()` is **not virtual**; a subclass override never runs. Use plain `prerequisiteType = FLAG`.
- `ETGModCompatibility.ExtendEnum<GungeonFlags>(guid, name)` values persist per save slot through MtG's `GameStatsManager.Save/Load` patches, but ids are assigned `max + 1` at registration, so they can drift when other flag-extending mods are added or removed.
- `GameStatsManager.ForceUnlock(string)` / `IsForceUnlocked(string)` are string-keyed and per-slot.
- `ItemDB.DungeonStart()` re-injects `ModLootPerFloor` into `Dungeon.baseChestContents` every run, so any loot-table removal must be re-applied per run.

```csharp
using System;

namespace PlutoTheCat
{
    /// <summary>Engine-free rules for the Shrine Stall: prices, unlock-flag naming and the unlock decision.</summary>
    public static class ShrineStallRules
    {
        public static int Price(string itemId, int[] prices, string[] ids)
        {
            if (itemId == null || prices == null || ids == null) return 0;
            for (int i = 0; i < ids.Length && i < prices.Length; i++)
                if (ids[i] == itemId) return prices[i];
            return 0;
        }

        private static string Suffix(string itemId)
        {
            if (string.IsNullOrEmpty(itemId)) return "";
            int colon = itemId.IndexOf(':');
            return colon >= 0 ? itemId.Substring(colon + 1) : itemId;
        }

        public static string FlagName(string itemId) { return "PLUTO_UNLOCK_" + Suffix(itemId).ToUpperInvariant(); }

        public static string MirrorKey(string itemId) { return "bogdan.etg.plutothecat:" + Suffix(itemId); }

        /// <summary>The string mirror wins, because extended flag ids drift when other mods are installed.</summary>
        public static bool Unlocked(bool flag, bool mirror, bool disabled) { return disabled || flag || mirror; }
    }
}
```
