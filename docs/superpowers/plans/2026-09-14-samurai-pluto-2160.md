# Samurai Pluto (Character 2.16.0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship spec part B: the samurai costume replaces Wet Pluto, unlocks only once Pluto's past is killed, starts with the Taiyaki Cannon and the katana, and shows its own boss-card bust; the normal skin gets the new Gemini bust.

**Architecture:** Art goes through the `pluto-artist` skill (Gemini first, `pixelize.py`, `review_art.py`); approved PNGs live in `reference/art/<piece>/` and `tools/make_art.py` copies them into Resources. Game logic: two new guns built like `KibbleSackGun`, a new `PlutoPatches.cs` with three Harmony patches (costume loadout, alt-gun shrine block, per-costume boss card), unlock and FPS settings in `Plugin.cs`/`PlutoConfig.cs`.

**Tech Stack:** C# net35 (Mono msbuild), BepInEx 5.4 + HarmonyX 2.7 (already referenced), Alexandria 0.5.10, Python 3 + PIL art pipeline, Gemini REST (`gemini-3-pro-image`).

Spec: `docs/superpowers/specs/2026-09-14-samurai-pluto-and-clinic-life-design.md` (commit 763b1bd), section B plus C and D.
Research: `research/costume_loadout.md`, `research/costume_bosscard.md`, `research/katana.md` (session scratchpad; the conclusions are copied into the tasks below).

## Global Constraints
- Console ids: `pluto:taiyaki_cannon`, `pluto:katana` (C3, Vet Visit logs them).
- Unlock gate: vanilla `CharacterSpecificGungeonFlags.KILLED_PAST` for Pluto's identity only (C1); debug key `UnlockSamuraiCostume`, default false.
- Samurai card files must NOT contain `bosscard_` (Alexandria would append them to the normal card).
- Every boss card set: 427x240, <= 30 % opaque, nothing at x<190,y<90, art in the left 45 %; both sets have the same frame count.
- Costume palette: haori `#2b3a67`, crest `#f0ece0`, hakama `#3a3a44`, obi/hachimaki `#b3202a`; Taiyaki `#5a3514/#b8742a/#e8b04a/#6b1f24`; sakura `#f7b7c8/#e98aa6`.
- New art rule: Gemini first, copied faithfully, pixel-perfect, reviewed with `pluto-artist` before the user sees it. Body frames stay row-strings (the kimono is copied from a Gemini sheet into row-string overlays).
- Shared tree: announce the file list to enter-the-gungeon-pluto-f1 before editing shared files; stage only this plan's paths; build logs to a file, check `$?`, never a pipe.
- Release with Vet Visit 0.14.0 on the drop page (C4); each session swaps only its own card.

```csharp
using System.Collections.Generic;
using HarmonyLib;
using UnityEngine;
using Alexandria.CharacterAPI;

namespace PlutoTheCat
{
    public static class PlutoPatches
    {
        public static PlayableCharacters Identity;
        public static List<Texture2D> NormalCard, SamuraiCard;

        public static void Apply(CustomCharacterData built)
        {
            Identity = built.identity;
            var h = new Harmony(Plugin.GUID + ".patches");
            h.Patch(AccessTools.Method(typeof(PlayerController), nameof(PlayerController.SwapToAlternateCostume)),
                    postfix: new HarmonyMethod(typeof(PlutoPatches), nameof(CostumeLoadout)));
            h.Patch(AccessTools.Method(typeof(FoyerAlternateGunShrineController), "Interact"),
                    prefix: new HarmonyMethod(typeof(PlutoPatches), nameof(BlockShrine)));
            h.Patch(AccessTools.Method(typeof(BossCardUIController), "ToggleCoreVisiblity"),
                    prefix: new HarmonyMethod(typeof(PlutoPatches), nameof(PickCard)));
        }

        // Costume decides the starting guns. The swap also runs before Start (inventory null) at
        // character select, quick restart and continue: set the flag only; Start picks the list itself.
        static void CostumeLoadout(PlayerController __instance)
        {
            try
            {
                if (__instance == null || __instance.characterIdentity != Identity) return;
                if (__instance.UsingAlternateStartingGuns == __instance.IsUsingAlternateCostume) return;
                __instance.UsingAlternateStartingGuns = __instance.IsUsingAlternateCostume;
                if (__instance.inventory != null && GameManager.Instance.IsFoyer) __instance.ReinitializeGuns();
            }
            catch (System.Exception e) { Plugin.Log("costume loadout: " + e.Message); }
        }

        // The alt-gun shrine toggles the same flag; for Pluto the costume is the only switch (vanilla skips Gunslinger/Eevee the same way).
        static bool BlockShrine(PlayerController interactor) => interactor == null || interactor.characterIdentity != Identity;

        static void PickCard()
        {
            PlayerController p = GameManager.Instance ? GameManager.Instance.PrimaryPlayer : null;
            if (p == null || p.characterIdentity != Identity || NormalCard == null || SamuraiCard == null || SamuraiCard.Count == 0) return;
            p.BosscardSprites = p.IsUsingAlternateCostume ? SamuraiCard : NormalCard;
        }
    }
}
```
