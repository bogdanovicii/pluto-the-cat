Vanilla reference: Pilot 14x21 visible (16x23 with the runtime outline), head ≈ 52-59 % of height,
1-px stick legs, eyes 1 px, no baked outline, 8-15 colours per character. 16 px = 1 unit.
Body clips come in `""` (two-handed gun: no paws drawn), `_hand` (one-handed gun: free paw drawn),
`_twohands` (no gun: both paws) variants; `_bw` = back-view side sprite (aiming up-diagonal).
`cc_sprite_placeholder.png` in a `_hand`/`_twohands`/`death_coop` folder falls back to the base clip.
